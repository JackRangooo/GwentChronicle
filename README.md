# Gwent Chronicle · 昆特战记

**面向《巫师之昆特牌》的 Windows 中文对局追踪、卡组管理与复盘工具。**

基于 [amkokot/GwentVision](https://github.com/amkokot/GwentVision) 开发，继承原项目的屏幕识别与卡组库能力，并扩展中文体验、连续采集、证据校对、段位追踪与原生桌面界面。本项目是非官方、非营利的玩家工具，与 CD PROJEKT RED 没有隶属或背书关系。

[下载最新版](../../releases/latest) · [详细使用说明](docs/使用说明.md) · [升级说明](CHANGELOG.md) · [反馈问题](../../issues) · [上游与许可](UPSTREAM.md)

## 相比原项目升级了什么

- **完整中文工作流**：中文界面、卡名、效果描述与搜索；识别语言可按实际游戏切换为简体中文或英文，适配中文卡组扫描与结算。
- **持续采集**：开始后，切屏、弹窗、菜单、结算和下一局不会自动停止；真实对局分段保存。只有用户主动停止或退出工具才结束采集。
- **先记录证据，再看参考**：实际观测、人工记忆补录、生成／变化卡分开；参考牌组不会冒充已经看见的牌。点击卡牌可查看图片、效果与来源，显式纠错并撤销。
- **整套卡组补录**：通过共享分页卡组库选一套牌作为未保存底稿，审阅增减后再确认；不必逐张输入，也不改写原始 `.gvm`。
- **更完整的复盘**：结果校对、可撤销删除、手动异常对局、双方独立姓名／段位／小局比分字段。缺失信息保持未确认，识别并非每次都能成功。
- **段位与碎片走势**：普通天梯 7～1 段按已确认胜负连续推算，可手动校准；异常对局可影响碎片，单独排除出卡组胜率。职业天梯与其他段位不能用同一碎片规则推算。
- **卡组库增强**：明确的重命名入口、社区玩法名建议、收藏、版本、导入导出、按金卡核心归集变种。选择器每页最多 40 套，避免一次加载几千个下拉项。
- **相近对手牌组**：至少 12 张合格的已观测／已确认卡，且候选牌组覆盖其 80% 以上，才最多推荐两套参考。相似度不是“对手必定使用这套牌”的概率。
- **曜石暗金 WPF 界面**：宽窗主列表加单个上下文区，紧凑窗保留开始／停止与底部动作；卡牌预览和各个工具窗口可独立置顶。
- **软件更新入口**：设置中主动检查 GitHub 正式发行版本，下载 ZIP 并核验 SHA256；用户退出工具后手动覆盖更新，保留自己的记录和牌库。

## 下载与开始使用

1. 在 [Releases](../../releases/latest) 下载 **`GwentChronicle-Windows-x64.zip`**。GitHub 的 “Source code” ZIP 是源码，不是可直接运行的安装包。
2. 将完整 ZIP 解压到有写入权限的独立文件夹，例如 `D:\Games\GwentChronicle`；无需放进游戏目录，也不需要另装 .NET。
3. 运行 **`启动昆特战记.cmd`**，或直接打开 `GwentVision\GwentVision.exe`。
4. 启动昆特牌，在工具的「设置 → 游戏界面语言」选择游戏内实际使用的语言。
5. 通过「本局使用 → 切换卡组」选中自己的牌组，再点 **开始识别**。仅浏览牌库不需要开始采集。
6. 结束采集时点 **停止识别**；切换页面和结算不会代你停止。

支持 Windows 10（19041+）／Windows 11，64 位。识别依赖 Windows OCR；中文游戏需安装系统的简体中文 OCR 语言组件。建议游戏采用 16:9，如 1920×1080，使用窗口或无边框模式，保持游戏画面可见。最小化或被遮挡会影响读屏质量，持续采集规则不代表能看见被遮挡的内容。

发行包首次启动会把公共初始数据复制到 `GwentVision/cache`；以后只补缺失文件，不覆盖已有牌库、设置或图片。为兼容此前版本，可执行文件、内部命名空间和本地数据目录仍保留 `GwentVision` 名称。

## 更新与数据保留

「设置 → 软件更新 → 检查更新 → 下载更新包」。下载成功会显示 SHA256 校验通过，再点「打开下载位置」。**先手动停止识别并退出工具，将新 ZIP 解压到原安装目录覆盖程序。** 不要在程序仍运行时替换文件。

发行包不携带运行时 `cache`、对局、姓名资料或校准文件；初始公共资料位于 `defaults/cache`。更新覆盖程序时不会把出厂牌库盖到用户牌库上。更新前仍建议备份 `GwentVision/cache` 与 `%LOCALAPPDATA%\GwentVision`。已有牌库不会被静默替换为新版出厂牌库；新社区资料可以明确导入合并。

程序不会自动安装、退出、重启或强制停止采集。检查更新仅向 GitHub 发送读取版本所需的请求，不上传对局或账号文件。GitHub 无法连接时可直接从发行页下载。

## 隐私、参考数据与边界

- 原始对局、独立人工修正、双方姓名、段位校准、截图与诊断保存在本机。**本仓库和发行包没有携带维护者的个人对局、账号、设置、私有牌库命名或本地 Git 历史。**
- 公开版默认关闭数据贡献服务，没有配置上游或维护者的接收端点；不会因使用中文版而自动上传对局。源码保留相关扩展能力，启用自己的服务必须自行配置并取得使用者同意。
- 诊断画面滚动保留最近最多 5 次采集会话，总预算 2 GB；清理不涉及原始对局、人工校对或牌库。
- 出厂牌库来自上游公共资料，是历史参考库，并非保证随时跟进版本的竞技排名。卡牌数据更新和软件更新是两项不同功能；实战牌表、费用及热门玩法请结合当前游戏版本核实。
- `data/community` 附带一份整理后的公开赛事示例牌表（43 个去重版本，32 个分组），可在卡组库导入。原图未标赛事年份和游戏版本；观众投票只用作人气参考，不能解释成实测胜率或当前强度保证。没有附带原始截图或个人对局数据。
- 读屏可能漏牌、误认，尤其是快速动画、生成牌与遮挡。卡组匹配、威胁估计属于参考，不能读取对手未公开的手牌或牌库，也不能代替用户核实。
- 暗金玻璃感使用原生渐变、高光和实色内容层，不是游戏背景实时折射或逐行模糊；可在设置降低透明度。

## 从源码构建与后续发布

需要 Windows x64 与 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。

```powershell
dotnet build GwentCompanion.sln -c Release
dotnet run --project tests/GwentCompanion.Tests/GwentCompanion.Tests.csproj -c Release -- --release-update-regression
pwsh ./tools/Build-WindowsRelease.ps1
```

成品在 `dist/GwentChronicle-Windows-x64.zip`。构建脚本做隐私检查、更新回归、初始化保留检查和自包含 Windows 打包，同时生成 `.sha256`。

维护者更新代码后，按 [发布流程](docs/发布与更新.md) 递增版本、提交并推送 `vX.Y.Z` 标签。GitHub Actions 会构建并发布 ZIP 与 SHA256；已安装程序的「检查更新」随后会读取该正式发行版本。

公开源码不附带私人像素回放语料。一些继承的开发诊断命令需要外部样例，不能把缺少样例的命令当成可直接运行的验收项；公开 CI 使用可移植的合成数据测试与初始化检查。
