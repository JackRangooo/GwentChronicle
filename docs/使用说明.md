# 昆特战记使用说明

## 安装

从本项目 Releases 下载 `GwentChronicle-Windows-x64.zip`，完整解压到独立、可写的文件夹，运行 `启动昆特战记.cmd`。不需要重装游戏或单独安装 .NET。不要只复制 EXE；`defaults`、`vision-assets`、运行库与卡图都是程序组成部分。

初次运行从 `defaults/cache` 复制缺失的公共资料到 `GwentVision/cache`。工具可以先打开牌库；采集需要实际运行昆特牌。中文游戏请在设置中选择简体中文，并确保 Windows 已安装简体中文 OCR 组件。

## 一次正常对局

1. 在卡组库中选中一套牌预览，点击“使用这套卡组”，或用实时页“切换卡组”进入共享选择器。
2. 确认“本局使用”横条显示正在玩的牌组，再开始识别。**选中预览和实际使用是两个状态。**
3. 对局中主列表首先显示实际观测与已确认的起始牌，可切换生成／变化记录。点击卡牌看效果与来源；ⓘ 可打开完整卡牌预览。
4. 发生误识别，在详情中明确点击移除一张，必要时撤销；整套记忆补录通过底稿窗口完成。
5. 工具持续采集，结算和下一局只分段保存。要结束采集，自己点击“停止识别”或退出工具。

切屏或最小化可能导致无法读取当时画面；工具保持运行和重试，不代表能识别不可见的牌。结算画面可停留几秒给姓名、段位和比分独立确认机会；未确认的字段可以在复盘中人工校对。

## 补录、纠错与复盘

“对局复盘”中展开对应对局，查看双方实际卡牌记录、结果、比分、段位与已有证据。点击“补录／校对卡牌”可按名字搜索单卡，也能从卡组库载入整套底稿，审阅增减后再明确保存。

参考卡组与已看到的牌分别展示。推荐需要至少 12 张合格的实录／已确认卡牌，且候选牌表覆盖其中 80% 以上，最多显示两个最相近结果。证据不足时不强行推荐。手动补录可能影响匹配结果，请只确认你能够核实的卡。

原始 `.gvm` 不被补录改写，人工校对写入独立记录。删除、恢复、结果编辑等沿用可撤销流程；提交修改前确认选中的对局和玩家一侧。

## 掉线异常与段位走势

未进游戏就网络判负等情况，可以在对局历史手动添加异常对局，填写实际时间、结果和说明。异常记录单独标记，不计卡组胜率，可按已确认结果参与碎片变化。

普通天梯 7～1 段按保存的胜负次序推算碎片；需要先校准实际段位和碎片。漏记、错误胜负或时间顺序会影响推算，应先校正对应记录。走势保留早期历史，后续校准不截断曲线。职业天梯与其他规则的低段位不采用这套简化碎片推算。

## 卡组库

支持搜索、阵营和领袖筛选、变种展开、版本切换、重命名、编辑、导入／导出与游戏内扫描。选择器每页最多 40 套；Ctrl+F 搜索，F2 重命名，窄窗口可返回列表。

重命名可以输入自己的名字，也可选择社区玩法名称建议。变种归集以金卡核心等条件衡量，并非同阵营同领袖就算完全相同。出厂库是历史公共参考，不能当成实时强度榜。

可选赛事示例牌表在 `GwentVision/data/community/autumn-masters.gwent-library.json`，通过卡组库的便携牌库导入功能审阅后合并。共有 43 个去重版本、32 个分组；保留公开选手来源与人气参考，未知赛事年份／版本不作虚构。

## 窗口与置顶

主窗口右上角“置顶”只影响该窗口，卡牌、卡组预览等窗口可以各自置顶。再次点击取消。使用显示菜单调整工作区、内容大小、多屏和全屏；F11 切换全屏，Esc 返回。

宽窗显示主牌表和一个上下文区，紧凑窗将详情放进同窗页面并提供返回。鼠标位于牌表中即可滚动；开始／停止和底部常用操作固定。

## 更新、备份与迁移

1. 设置 → 软件更新 → 检查更新。
2. 有新正式版本时下载更新包，等待显示 SHA256 校验通过，再打开下载位置。
3. **手动停止识别并退出工具**，将 ZIP 解压到原安装文件夹，覆盖程序文件。
4. 用原入口重新启动。发行包没有运行时 `cache` 或个人数据，defaults 仅补缺失文件。

重要数据分两处：安装目录 `GwentVision/cache`（牌库、命名、设置等），以及 `%LOCALAPPDATA%\GwentVision`（原始对局、校对、姓名、校准等）。备份或换电脑时同时保留这两处。不要把这些文件公开提交到 GitHub。独立出厂资料更新不会静默覆盖既有自定义牌库；新资料请导入合并。

检查／下载更新不会自动停止采集，也不会自动覆盖正在运行的程序。下载在 `%LOCALAPPDATA%\GwentVision\updates`。仅升级程序不需要上传任何本地记录。

## 常见问题

**Steam 报 `LoadLibrary failed with error 87`：** 可能是 CDPR REDlauncher 初始化失败，不能仅凭错误码断定游戏损坏。可尝试游戏属性 → 通用 → 启动选项加入 `--launcher-skip`，跳过启动器；若仍报错需另查日志。

**没有卡图／界面没有数据：** 确认完整解压，首次初始化可写，并未直接在 ZIP 内运行。请勿只下载 GitHub 的 Source code 包。

**没有识别中文：** 检查游戏语言与工具设置一致、Windows 中文 OCR 可用，游戏画面可见。缩放、非 16:9、快速动画和遮挡可能降低准确度。

**找不到对手名字或段位：** 这些字段独立识别，缺失会保持未确认，不用己方信息代填。可以在复盘中校对。

**GitHub 更新检查失败：** 网络、访问频率限制或发行附件尚未上传完都会导致失败。可以稍后重试，或从发行页手动下载。不要从陌生来源替换 DLL。

## 本地数据与隐私

公开版默认没有启用数据贡献接收服务。姓名、账号相关资料、对局和诊断不随软件更新上传。反馈问题时，先遮盖自己的和对手的名字、账号标识、路径与私人牌组；不要直接上传整个数据目录。
